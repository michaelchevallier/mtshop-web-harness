CSP-strict test page

This page exists specifically to test the CSP-exemption behavior of native-injected bridge code (MOBILE-20276, Part D row 8). It is served with a strict Content-Security-Policy meta tag above — if you can read this paragraph and see the marker below, the page itself rendered despite the strict policy. The open question is whether a mobile SDK's native-injected WebView bridge/recorder is exempt from this page's own CSP, or is blocked by it the same way a page-hosted script would be.
